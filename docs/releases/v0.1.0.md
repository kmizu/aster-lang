# ASTER v0.1.0

ASTER 0.1 is the first complete experimental vertical slice of a deterministic,
auditable language and runtime for governed AI agents.

The release is a reference processor. It uses synthetic fixture-backed model,
read, approval, and write drivers; it is not production-ready and does not
connect to live providers.

## What is implemented

- A parser, canonical formatter, stable diagnostics, name resolution, types,
  effects, capabilities, policy purity, taint rules, and affine-use analysis.
- A typed serializable IR with explicit control flow and effect suspension.
- A deterministic runtime with exact capability grants, pre-effect budget
  reservation, transactional state, snapshots, resume, and canonical
  SHA-256-chained traces.
- Semantic replay that re-steps the program, checks every request identity and
  budget transition, and has no external driver parameter.
- A meeting-scheduler example that crosses the complete governed write path.

## The authority boundary

ASTER makes four transitions explicit:

```text
Candidate<T> -> Proposal<A> -> Permit<A> -> Reconciled<A>
model data       action intent   authority     checked reality
```

A model produces an opaque `Candidate`; it never executes a tool or receives
ambient authority. Reads run only through `observe`. Writes run only through
`intent -> propose -> authorize -> commit`, and a successful receipt must be
checked by a later observation before state is published.

## Install

Download the archive for your platform from the assets attached to this
release:

- `aster-v0.1.0-x86_64-unknown-linux-musl.tar.gz`
- `aster-v0.1.0-aarch64-apple-darwin.tar.gz`
- `aster-v0.1.0-x86_64-apple-darwin.tar.gz`
- `aster-v0.1.0-x86_64-pc-windows-msvc.zip`

Linux and macOS archives contain `aster`; the Windows archive contains
`aster.exe`. Every archive also contains `README.md` and `LICENSE`.

After extraction:

```bash
./aster --version
```

The expected output is `aster 0.1.0`.

## Verify the download

Download `SHA256SUMS` into the directory containing the four archives, then
run:

```bash
sha256sum --check SHA256SUMS
```

The checksums detect damaged or substituted downloads. The 0.1.0 binaries are
not code-signed or notarized, so SHA-256 verification does not establish
publisher identity.

## Try the meeting scheduler

Clone or download the source repository so the example and its synthetic
fixtures are available, then run:

```bash
./aster check examples/meeting-scheduler/main.aster
```

The complete record and replay commands are documented in the repository
README. Replay consumes the recorded trace without constructing or invoking an
external driver.

## Experimental scope and limitations

ASTER 0.1 intentionally excludes live provider integrations, arbitrary network
or shell access, FFI, packages and imports, concurrency, loops, recursion,
self-modification, distributed execution, and production key management.

Traces and snapshots may contain private non-secret fixture data. Treat them as
sensitive artifacts. `Secret<T>` values are forbidden from prompts, ordinary
logs, diagnostics, traces, snapshots, persistent state, and string conversion.
